TikTok cache guide

Bersihkan cache TikTok

  1. Buka TikTok, lalu masuk ke tab Profil.
  2. Ketuk ikon menu ☰ → Pengaturan dan privasi.
  3. Pilih Ruang kosong / Free up space atau menu sejenis.
  4. Tekan Hapus pada bagian Cache. Tinjau bagian Unduhan sebelum menghapus.
Nama menu dapat berubah mengikuti versi aplikasi. Menghapus cache berbeda dari menghapus data aplikasi. Jangan menghapus draft, unduhan, atau data penting tanpa memeriksanya lebih dahulu.
